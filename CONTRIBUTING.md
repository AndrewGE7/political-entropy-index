# Contributing to the Canonical Work

Only **Age Old LLC** (Andrew Eppler) may change the book, the PEI formula,
the dashboard, or the curriculum.

This repository is public so researchers can *read* the instrument and
*attach* data. It is not a community-maintained fork surface.

## You may

- Open an **issue** with a research note, error report, or citation.
- Submit an **Adapter Manifest** (JSON/CSV matching `public/adapters/schema.json`).
- Publish adapters in your own repository under your own license.
- Cite PEI with a link back to the official source.

## You may not (and PRs will be closed)

- Pull requests that edit manuscript text, weights, phase bands, UI, or brand.
- Rebrands, “community editions,” or formula experiments presented as PEI.
- License or trademark changes.

If Age Old LLC wants a change in the Canonical Work, it will be committed
only from the copyright holder’s account, on a protected `main` branch.

## Adapter review

Open an issue titled `adapter: <name>`. Include source, dimension, invert
flag, and a sample of ten country rows. Certification is optional and
unilateral.

## GitHub settings (this repository)

- CODEOWNERS: `* @AndrewGE7`
- `main` is protected against force-push and deletion
- Wiki should stay off; unofficial Pages sites may not use the marks
- Adapter issues only — Canonical Work PRs are closed
