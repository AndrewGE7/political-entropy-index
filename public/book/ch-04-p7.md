### The PEI Calculation Formula

The Political Entropy Index is calculated by summing the weighted contributions from all six dimensions:

```
PEI = PEI_inequality + PEI_stability + PEI_conflict + PEI_energy + PEI_info + PEI_environment

Where:
PEI_inequality    = (Gini / 100) × 25
PEI_stability     = ((10 - Polity) / 20) × 20
PEI_conflict      = (Conflict_Score / 100) × 20
PEI_energy        = ((100 - Energy_Security) / 100) × 15
PEI_info          = ((100 - Freedom_Score) / 100) × 10
PEI_environment   = ((100 - Environmental_Score) / 100) × 10
```

**Simplified Formula:**
```
PEI = (Gini × 0.25) + (((10 - Polity) / 20) × 20) + (Conflict × 0.20) + (((100 - Energy) / 100) × 15) + (((100 - Freedom) / 100) × 10) + (((100 - Environment) / 100) × 10)
```
